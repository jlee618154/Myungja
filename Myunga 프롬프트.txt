# MYUNGJA 쇼핑몰 홈페이지 최종 제작 프롬프트 (보완판)

첨부된 MYUNGJA 프로젝트 파일과 이미지 자료를 분석하여, 40~50대 여성을 위한 프리미엄 액티브웨어 쇼핑몰 홈페이지를 완성해 주세요.
기존 프로젝트의 정상 작동하는 기능과 상품 정보를 유지하면서 아래 요구사항을 전체 파일에 일관성 있게 적용해야 합니다.
**임시 이미지, 빈 화면, 연결되지 않는 메뉴, 더미 상품은 절대 사용하지 마세요.**

> ⚠️ **이 프로젝트는 데스크톱 전용입니다.** 모바일/태블릿 반응형 대응은 필요하지 않으며, 기준 해상도 1440px(최소 1280px) 기준으로만 레이아웃을 설계해 주세요. 미디어쿼리 기반 모바일 최적화 작업은 하지 않아도 됩니다.

---

## 0. 기술 스택 및 데이터 저장 방식 (신규 추가)

이 프로젝트는 Supabase MCP가 이미 연동되어 있습니다. 아래 기준으로 데이터를 저장해 주세요.

- **회원 인증**: Supabase Auth 사용 (이메일/비밀번호 방식)
- **DB 테이블 구성** (Supabase Postgres):
  - `products` (상품 기본정보), `product_options` (색상/사이즈/재고)
  - `orders`, `order_items` (주문/주문상품)
  - `cart_items` (회원 장바구니 — 비회원은 localStorage, 로그인 시 병합)
  - `reviews` (리뷰), `coupons`, `points` (적립금)
  - `addresses` (배송지 관리)
- **RLS(Row Level Security)**를 모든 사용자 데이터 테이블에 적용해, 본인 데이터만 조회·수정 가능하도록 설정해 주세요.
- 비회원 장바구니/찜은 브라우저 저장(localStorage)에 유지하고, 로그인 시 Supabase의 회원 데이터와 중복 없이 병합해 주세요.

### 레이아웃·여백 규칙

- **스페이싱 단위**: 4px 기준 배수 사용 → 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px
- **기준 해상도**: 1440px 너비 기준으로 디자인 (최소 지원 너비 1280px)
- **컨테이너 최대 너비**: 1280px, 좌우 여백 최소 64px
- **버튼 모서리(border-radius)**: 2px (직각에 가까운 미니멀한 형태, 과도한 둥근 모서리 지양)
- **카드 이미지 모서리**: 0px (각진 형태 유지, 편집숍 톤 강조)
- **버튼 높이**: 52px
- **그림자**: 카드·드롭다운에는 매우 옅은 그림자만 사용 — `0 4px 16px rgba(59, 44, 34, 0.08)`

### 상태별 스타일 규칙
- 링크/버튼 hover: 다크 브라운 → 소프트 오렌지로 텍스트 또는 보더 색상 전환 (트랜지션 0.2s ease)
- 포커스(키보드 탐색): 소프트 오렌지 2px 아웃라인 (`outline: 2px solid #E08A4C`)
- 품절/비활성: 불투명도 40% + 대각선 오버레이

## 2. 헤더 및 내비게이션

### 메뉴 구성 (수정: 실제 등록 상품 수에 맞춰 정리)

현재 등록된 실제 상품은 TOP·BOTTOM·OUTER 3개뿐이므로, "더미 상품 금지" 원칙을 지키기 위해 아래처럼 메뉴를 구성하는 것을 권장합니다.

- **상위 메뉴(고정 4개)**: TOP / BOTTOM / OUTER / ABOUT
- **MD PICK, NEW**는 별도 카테고리 페이지가 아니라 **홈페이지 내 섹션**으로만 노출 (실제 상품 3개를 활용해 코디 형태로 소개)
- **SET**은 상품이 2벌 이상 조합될 때만 의미가 있으므로, 현재는 메뉴에서 제외하고 추후 세트 상품이 실제로 등록되면 추가

> 📌 만약 앞으로 카테고리별 상품을 추가로 등록하실 계획이라면, 그 상품 정보(상품명·가격·색상)를 먼저 확정해서 알려주시면 메뉴 구조를 다시 넓혀 반영해드릴게요.

### 왼쪽
- MYUNGJA 로고 → 클릭 시 홈페이지로 이동

### 가운데 메뉴
- 위 4개 메뉴에 마우스를 올리면 하위 메뉴가 드롭다운으로 표시
  - TOP 하위: 시그니처 에어핏 브라탑 (현재 1개 — 추가 등록 시 자동 확장되는 구조로 설계)
  - BOTTOM 하위: 소프트 저지 레깅스
  - OUTER 하위: 스웨이 온더고 자켓
- 부드러운 페이드인 + 아래로 펼쳐지는 애니메이션
- 마우스가 상위 메뉴~하위 메뉴 영역을 벗어나면 자연스럽게 닫힘 (호버 영역 연결 처리)
- 활성/호버된 메뉴에는 밑줄 또는 색상 변화 효과
- 충분한 z-index로 다른 콘텐츠 위에 표시
- 키보드 포커스(Tab)로도 드롭다운 열기 가능하도록 접근성 지원

### 오른쪽
- 검색 / MY(마이페이지) / 장바구니(bag, 담긴 수량 배지 표시)

글씨체, 글씨 크기, 메뉴 간격, 헤더 높이, 좌우 여백과 정렬이 모든 페이지에서 동일해야 합니다.

## 3. 메인 홈페이지

### 3-1. 메인 비주얼 (히어로 캐러셀)
- 화면 너비·높이를 가득 채우는 풀스크린 히어로 이미지 캐러셀 (첨부 사진 3장)
- 4초마다 자동 전환, 마지막 이미지 후 첫 이미지로 무한 반복
- 크로스페이드 + 가벼운 줌인 전환 효과
- `object-fit: cover` 적용, 이미지별 초점 위치(object-position) 조절 가능하게 구현
- 사진 위 은은한 다크 그라데이션 오버레이 (텍스트 가독성 확보)
- 하단 중앙 페이지네이션 도트 3개 — 클릭 시 해당 이미지로 이동, 전환 시 활성 도트 함께 변경
- 마우스 호버 시 자동재생 일시정지
- 이전/다음 버튼 (좌우 화살표)
- `prefers-reduced-motion` 감지 시 애니메이션 최소화

### 3-2. MD PICK (활동별 추천 코디)
- 등산 / 마라톤 / 요가 — 3개 카드
- **실제 등록된 3개 상품(에어핏 브라탑·저지 레깅스·온더고 자켓)의 색상을 조합**해 각 활동에 맞는 코디 구성
- 각 카드에 이미지 + 활동과 브랜드 철학을 연결한 짧은 설명 문구

### 3-3. ABOUT MYUNGJA
- ABOUT 메뉴 클릭 시 아래 소개 영역으로 스크롤 이동
- 전체 폭 다크 브라운 배경
- 상단 작은 텍스트: "ABOUT MYUNGJA" (소프트 오렌지)
- 중앙 큰 문구: "몸을 조이지 않고, 삶의 속도를 따라가는 옷. 명자는 애쓰지 않는 편안함을 가장 아름다운 태도라 믿습니다." (핵심 구절은 소프트 오렌지로 강조)
- 하단 얇은 구분선 + 브랜드 설명 2단 배치 (기존 문구 그대로 사용)

### 3-4. 화면 기준 (신규 추가)
- 데스크톱 전용 (반응형 미지원), 기준 해상도 1440px, 최소 지원 너비 1280px
- 이미지·폰트는 로딩 중 레이아웃 흔들림(CLS) 없도록 스켈레톤 또는 고정 비율(aspect-ratio) 처리

## 5. 등록 상품과 상세페이지

### 공통 옵션 UI
- **색상**: 원형 컬러 스와치 버튼. 클릭 시 해당 색상의 실제 착용·상세 이미지로 크로스페이드 전환 (CSS 필터로 색만 바꾸는 방식 금지). 메인 이미지+썸네일 갤러리 전체가 함께 교체. 선택된 색상은 테두리/체크 아이콘으로 표시하고 색상명도 텍스트로 병기. 품절 색상은 흐리게 + 대각선 처리로 선택 불가.
  - 색상별 이미지가 없는 경우: 기본 이미지 + "해당 색상 이미지를 준비 중입니다" 안내 (다른 색상 이미지를 대체 사용 금지)
- **(신규 추가) 사이즈**: S / M / L / XL 버튼 (원단 특성상 넉넉한 핏 기준 표기). 재고 없는 사이즈는 흐리게 처리 + 선택 불가.
  - 사이즈 버튼 옆 "사이즈 가이드 보기" 링크 → 사이즈 표 팝업 (실측 치수는 제품 등록 시 함께 입력)

## 9. 회원가입과 로그인

### 회원가입 폼
- 이메일(형식 검증 + 중복 확인) / 비밀번호(8자 이상, 영문·숫자·특수문자 조합) / 비밀번호 확인 / 이름 / 휴대전화(인증번호 발송·인증) / 생년월일(선택) / 성별(선택) / 배송지 주소(우편번호 검색, 기본/상세 주소)
- 전체 동의 및 개별 약관 동의 체크박스 (이용약관·개인정보 수집이용 동의는 필수, 마케팅 수신 동의는 선택)
- 입력란 아래 즉시 오류 메시지, 필수 항목 미충족 시 가입 버튼 비활성화
- 비밀번호 표시/숨기기 버튼
- 비밀번호는 Supabase Auth 기본 해시 방식으로 저장 (평문 저장 금지)
- 이미 가입된 이메일이면 "이미 사용 중인 이메일입니다" 안내 + 로그인 페이지 링크

### (신규 추가) 로그인 및 비밀번호 찾기
- 로그인 폼: 이메일 + 비밀번호
- **비밀번호를 잊으셨나요? 링크 추가** → 가입한 이메일로 재설정 링크 발송 (Supabase Auth의 비밀번호 재설정 기능 활용)
- 로그인 실패 시 "이메일 또는 비밀번호가 일치하지 않습니다" 안내 (이메일 존재 여부는 노출하지 않음)

상단 메뉴의 회원가입 클릭 시 회원가입 페이지로 이동. 키보드 조작, 라벨, 오류 안내 등 접근성 지원.
